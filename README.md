# TabiFlow — GitHub Pages版

旅程・地図・予算・持ち物・メモをまとめて使う、スマートフォン向け旅行アプリです。

## GitHub Pagesへの公開

1. このZIPを展開します。
2. `TabiFlow_GitHubPages` フォルダー内の **`index.html`・`sw.js`・`manifest.webmanifest`・`icons` フォルダー**を、GitHubリポジトリの公開フォルダー直下へアップロードします。4点を同じ階層に置いてください。
3. GitHubリポジトリの **Settings → Pages** で公開元ブランチとフォルダー（通常は `main` / `/(root)`）を選び、Pagesを有効にします。
4. 発行された `https://...github.io/.../` のURLをスマートフォンで開き、オンラインの状態で一度読み込んでください。
5. ブラウザの「ホーム画面に追加」またはアプリの「アプリ化」からホーム画面に登録します。

## 重要：公開リポジトリと旅行データの保護

この配布版の初期画面は空のテンプレートです。公開GitHubリポジトリに旅行日・行き先・予約・支出などが含まれないようにしています。旅行データはブラウザのローカルストレージに保存され、HTMLやGitHubリポジトリには書き戻されません。

**JSONバックアップには個人的な旅行情報が含まれます。公開リポジトリへコミットしないでください。**

## 重要：元のデータを引き継ぐ

ブラウザの保存領域は、ローカルHTML版・GitHub Pages版・別ブラウザ・別端末で別々です。

- 古いTabiFlowを開き、**旅行設定 → バックアップ保存**でJSONファイルを保存。
- GitHub Pages版を開き、**旅行設定 → バックアップ読込**でそのJSONを読み込みます。
- 読み込み後、日程・予算・持ち物・メモ・支出を確認してください。

旅行前にGitHub Pages版でもう一度バックアップを保存し、JSONを端末内とクラウド等の2か所に保管してください。

## オフラインで使える範囲

- 端末内に保存済みの旅程・予算・持ち物・メモ・支出：利用可能
- すでに一度表示した地図タイル：キャッシュが残っていれば表示可能
- まだ表示していない場所の地図、住所検索、天気更新、Googleマップへの移動：インターネット接続が必要
- CDNのスタイル・地図ライブラリ：最初にオンラインで開いた際にキャッシュを試みます。出発前にオンラインでアプリを一度開き、地図も必要な範囲まで表示しておいてください。

オフライン表示は「一度オンラインで開いてキャッシュが準備された後」を前提とします。旅行当日に初回起動をしないでください。

## 通知について

予定通知は、アプリが起動している間にブラウザの通知機能を使って確認します。アプリを完全に終了している間の通知は保証されません。通知許可とOS側の通知設定も必要です。確実なアラームとしては、端末標準のカレンダーにも予定を出力してください（旅行設定 → 日程をカレンダーに追加）。

## 候補URLについて

SNSなどのURLはリンクを候補として保存します。投稿本文や住所を自動取得できない場合は、地図位置を推測で付けません。候補をしおりへ追加した後、必要に応じて場所を編集してください。

## データの扱い

旅程・個人メモ・支出は利用中ブラウザのローカルストレージに保存します。天気を取得すると旅行先の座標をOpen-Meteoへ、スポット名を検索すると入力した場所名をNominatimへ送信します。地図タイルはEsriから取得し、Googleマップは利用者がリンクを押したときに開きます。ブラウザのデータ削除・端末変更・別ブラウザへの変更では保存データが消えるため、JSONバックアップを保管してください。
